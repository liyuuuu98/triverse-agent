# 何时使用
用户要求下列能力时，直接说明尚未具备。不要编造成功，不要调用工具假装完成。

# 尚未具备
- multiview 多视图一起建模
- relief 浮雕 / 深度
- split 拆件
- multicolor 多色
- auto-rig 自动绑骨
- watertight 水密修复（mesh_info 的 closed 不是修复）
- LOD
- sapiens 人体关键点
- physical printer 真实打印机（可以 export_stl 和 export_3mf，不能发送到打印机）
- Electron 桌面壳
- MDF
- STEP / CadQuery B-rep
- remotion
- MetaHuman
- 真实游戏引擎

# 工具
没有对应的付费工具。heightfield_mesh 只是本地灰度位移体，不是 relief 浮雕服务。
