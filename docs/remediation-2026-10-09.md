# 修复与技能清理记录

修复开始：2026-10-09（Asia/Shanghai）。范围为当前本地 Pi 项目，未修改 Hi3D 服务、未部署集群、未消耗生成/导出额度。

## 已修复

| 审查问题 | 当前实现 |
| --- | --- |
| 旧 confirm 审批绕不过真实 quote/create | 真实 MCP schema、完整 prompt/source/visibility/额度绑定、30 分钟收据、原子一次性批准、完整请求展示与拒绝 |
| Agent 可改审批文件 | control 在 workspace 外；通用写入与 Shell 保护内部元数据、场景、快照和生成结果 |
| 未知创建容易重复付费 | 发送前保存 operation UUID，重复 ID 拒绝，后台只查询/刷新原任务 |
| 本地图无法接入云端 | upload_reference 计算指纹，稳定输入 ID，宿主 PUT，READY/大小/MIME/哈希校验，未知结果仅查询 |
| 导出没有可靠交付 | 单独批准、稳定 export ID、无自动转换/付费重试、HTTPS 下载、校验、历史/provenance、幂等入场景 |
| tasks/history 只是空文件 | 后台记录任务/账单/恢复动作，页面轮询、下载、历史资产比较 |
| 场景参数不执行 | protocol 校验+版本冲突；视口执行变换、层级、相机、目标、灯光、可见性、线框和内嵌动画 |
| 检查数据过于简单 | 二进制几何、有界拓扑、节点变换 bounds、不同 primitive 模式、缺失 UV/法线等警告 |
| Shell 只有 cwd 没有隔离 | sandbox-exec/bubblewrap 检测、断网/限定文件访问，无可用隔离则禁用 bash |
| HTTP 对外无认证 | 对外监听强制密钥、HttpOnly SameSite cookie、Origin/本地 Host 检查、保护内部文件下载 |
| JSON/聊天写入不可靠 | 原子 JSON、损坏显式失败、250ms 合并独立快照、最终落盘和运行锁清理 |
| 技能重复且旧项目不更新 | 8 技能依赖目录、完整资源按哈希同步、退役清理、自定义保留、缺依赖禁用自动调用 |
| 旧项目说明/授权不安全 | 更新当前规则、历史文件有限迁移并标未验证，不继承旧批准记录 |
| OAuth 环境/托管回调固定 | metadata/clientId 可配置，可使用预先注册的 HTTPS 回调；保留 loopback+state 粘贴流程 |

## 技能删减

原 114 个技能中删除 110 个，保留并重写 4 个，新增 4 个；最终 8 个：

| 技能 | 用途 |
| --- | --- |
| service-select | 仅按真实工具和 profile 路由 |
| create-game-ready-asset | 文生资产、明确预算与审查；不冒充远程减面/渲染 |
| image-to-model | 云端 READY 图输入到模型 |
| retexture | 明确所属模型版本，文字或参考图重新贴图 |
| mesh-audit | 免费本地 GLB 与有限拓扑审查 |
| scene-edit | 真实场景编辑、快照、冲突处理 |
| delivery-review | 报告、预算、可下载 GLB/本地 ZIP |
| task-recovery | 原 operation/export 恢复、结算和状态同步 |

删除的是本项目复制的旧技能。游戏网络/经济/战斗等细分流程、音视频制作、旧 Canvas 应用、CAD/打印产品模板、绑骨/头发/多视图/远程减面渲染等没有当前执行工具或重复细分，直接清理。逐项名称见 [清理清单](skill-cleanup-2026-10-09.json)。退役名单也用于清理已有项目副本。

Hi3D 的游戏 demo、绑骨/动作/低模人头、打印拆分/切片等是其产品功能；删除这些本地技能不会获得或移除对方服务能力。今后若实际接入对应工具，应按用户任务补一个可验证技能，而不是恢复整套模板。

## 验证与限制

测试覆盖真实 23 工具输入合同及模拟 MCP/传输：完整审批、单次/并发消耗、过期、重复 operation、上传未知结果恢复、账单、下载指纹拒绝和一次场景插入；另覆盖几何、版本、打包、认证和场景冲突。

最终本地测试 44 项：43 项通过、1 项因系统沙箱限制跳过；protocol/gateway/web 构建和 TypeScript 检查通过。8 个技能通过 skill-creator quick_validate。

系统隔离不可用时关闭 Shell 的行为通过测试；当前运行环境不允许实际嵌套系统沙箱，所以实际隔离执行检查跳过，不将其计作已实测。真实远程付费链路和模型质量未验收；原始结果不是唯一自包含 GLB 时会报告需明确转换/选择，不自动消费额外额度。

尚未提供多用户租户隔离，也未接入远程重网格/绑骨/动作/打印服务。这些属于外部能力或产品扩展，不能用修订技能文案代替实现。旧集群部署仍需同步构建、配置访问 Secret 并重启后才能应用这些修改。
