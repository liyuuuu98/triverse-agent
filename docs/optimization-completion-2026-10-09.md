# 本轮优化与修复交付

日期：2026-10-09 至 2026-10-10。针对 Triverse Pi 工作区，保留并合并了同目录另一项任务的技能、图片生成、流程和安全改动。以下记录源码实现；没有部署到集群，也没有运行真实付费生成或导出。

## 已实现

- **真实 MCP 审批**：独立 quote/create 协议；完整 prompt/source/profile、公开或私有、费用上限及 operation_id 绑定；报价默认参数归一化、30 分钟有效期、schema 校验、单次授权及并发防重。不确定结果保留原操作查询恢复。
- **宿主业务流程**：参考图指纹上传与 READY 校验、后台任务同步、导出意图审批、原 export_id 恢复、下载大小和可用 SHA-256 校验、生成模型登记到本地场景及历史。文件传输限制公开 HTTPS 地址、大小和时间；租约不交给模型 shell。
- **能力与技能**：旧 114 项精简为 8 条真实核心流程；迁移既有项目并复制完整资源包，保留自定义技能。能力面板按实际所需工具显示 ready/needs-tools/planning，缺依赖的技能不自动调用。
- **场景编辑**：位置、XYZ 旋转、缩放、层级、可见性、灯光及相机预设；前端对象列表与变换表单；非法输入与循环层级拒绝，版本冲突返回 409，场景原子写入。旧场景按原排列迁移。
- **GLB 预览**：实际包围盒聚焦及选择框、六个视角、线框/渲染模式、已有骨骼动画播放、PNG 下载、可见加载错误。对象变换和选中变化复用模型缓存；同路径文件更新用重新加载按钮刷新。历史并排预览。
- **检查与交付**：读取实际二进制几何，汇总 primitive 模式、静态世界空间尺寸、UV/法线缺失、纹理/骨骼/动画；有界拓扑检查包含边界、非流形边、绕序、退化面和连通分量。版本备份带 hash；ZIP 包含 GLB、场景和 manifest，保留父变换及相对路径，聊天提供下载入口。
- **合并的基础修复**：图片生成工具与消息内预览、模型失败状态、串行消息快照、保护审批与版本元数据、符号链接越界拒绝。公网监听要求工作区访问令牌；shell 仅在操作系统隔离可用时暴露。

## 验证与边界

本地契约测试使用已发现的 23 工具 schema；覆盖三种付费创建的参数绑定、单次授权、失败报价、上传响应不确定恢复、导出响应不确定恢复、错误下载指纹、登记防重复、旧技能同步、场景并发写入及真实 GLB fixture。

完整 `npm test`：43 项，39 通过，1 跳过，3 失败。3 项失败均为本地 HTTP 服务监听 `127.0.0.1` 被沙箱拒绝（`listen EPERM`）；1 项隔离执行测试因 OS sandbox 在当前环境无法启动而跳过，同时验证了不暴露未隔离 shell。不能把这个结果称为完整测试通过。

网关和前端 TypeScript 检查、protocol/gateway/web 生产构建通过；最终前端构建约 3 分 39 秒。主入口约 585 KB、视口约 1,028 KB（压缩前），仍有大分块提示。MCP 模拟测试验证代码契约和恢复行为，不代表云端服务的质量、扣费或真实文件交付已经验收。预览 UI 尚需在可启动本地服务的环境进行浏览器交互检查。

为完成端口测试请求的提权执行被自动审批服务因额度不足拒绝，命令未执行；这不是对代码安全性的否定，也没有绕过审批。剩余端口测试需在审批服务恢复或允许监听的环境完成。

拓扑审计上限为 500,000 三角形，按 mesh 内相同坐标焊接统计；压缩或稀疏 accessor 等会报告不完整。没有测试自相交、顶点流形、薄壁、尺寸公差或真实骨骼变形，不能据此认证可打印或游戏生产就绪。

## 后续优先级

1. **上线验收**：在允许监听的环境重跑完整测试与浏览器检查，配置 WORKSPACE_ACCESS_TOKEN、HTTPS/OAuth 回调并更新实际部署；备份旧项目数据，核对旧账本与新 control 存储迁移。先做文字/图片/重贴图各一条受控付费验收，核对任务、账单、下载、历史、场景及 ZIP。
2. **优化处理工具**：接入真实减面/重拓扑、UV、烘焙和 LOD；增加纹理分辨率预算、枢轴和目标引擎导入验收。这些不由新增 skill 自动获得。
3. **部件与角色**：多视图生成、语义拆件与补全、绑骨、动作生成/重定向；当前只能播放模型已有动画。
4. **专项生产流程**：打印方向接薄壁/自相交/修复、STL/3MF、切片验证；CAD 方向需独立内核和公差验证。按首批用户目标选择一条推进。
5. **Agent 产品体验**：候选概念图/编辑与批次风格约束、自动截图视觉评审、明确迭代预算、统一用量展示；多人使用需每用户凭据与项目权限，当前访问令牌不是多租户账号体系。
