---
name: retexture
description: Change the texture of an owned generated model using text or a reference image while preserving the original version.
---

Resolve the selected scene object and its cloud provenance. Choose the exact eligible asset/item/file/candidate from list_retexture_sources; never substitute a different version. Use text mode or an owned READY image source; upload_reference handles a local reference image. Select only supported texture sizes.

Quote the exact source and texture intent, then request_creation_approval including mode, complete text/image reference, texture_size, explicit visibility, stable operation_id and max_credits. Wait for approval and create once. Preserve the original file; wait for the separate export approval, then host delivery registers a new immutable version with provenance. Compare the old and new assets and report the actual result. A texture change is not a geometry edit.
